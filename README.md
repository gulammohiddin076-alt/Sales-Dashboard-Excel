# 📊 Sales Dashboard – Excel Project

This project is a professional Sales Dashboard created in Microsoft Excel.  
The purpose of this dashboard is to analyze sales performance using charts, KPIs, and region-wise breakdown.

---

## 📁 *Project Files*
- *Sales Data.xlsx* – Raw dataset of sales  
- *Sales Dashboard.xlsx* – Final dashboard with charts and KPIs

---

## 📈 *Dashboard Highlights*
- *Monthly Sales Trend Chart*
- *Region-wise Sales Analysis (Karachi, Lahore, Islamabad)*
- *Top Product Analysis (Perfume A, B, C)*
- *Total Sales & Total Quantity KPI Cards*

---

## 🔧 *Tools Used*
- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Slicers  
- Basic Data Cleaning  

---

## 🎯 *Key Insights*
- Perfume B is the *best-selling product*  
- Islamabad shows *highest sales regionally*  
- Dashboard includes interactive visuals for better analysis
